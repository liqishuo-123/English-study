# 海报说明 + 文生图提示词

## 一、这次交付的海报不是"AI 画图"，是排版渲染出来的

所以在**尺寸和清晰度上是精确的**，不是靠模型猜：

| 项目 | 值 |
| --- | --- |
| 成品 | `poster-a3-300dpi.png` / `poster-a3.pdf` |
| 物理尺寸 | A3 竖版 297 × 420 mm |
| 像素尺寸 | **3508 × 4961 px** |
| 分辨率 | 300 DPI（PNG 内已写入 pHYs = 300dpi，Photoshop/Word 里显示就是 A3） |
| 文字 | HTML 文本，300dpi 下依然是矢量级锐利边缘（非位图放大） |
| 二维码 | 内含，指向在线地址，已用 OpenCV 实测可解码 |

复现方式（改文案、换配色、重排都能一键重出）：

```powershell
# 1) 演示截图（3 倍像素密度，会自动写入演示进度数据）
node tools/shot-hires.mjs http://127.0.0.1:8123/ ..\_poster\shots
# 2) 渲染海报（自带几何自检：溢出/重叠/裁切会报出来）
node tools/poster-shot.mjs ..\_poster\poster.html ..\_poster\poster-a3-300dpi.png
```

## 三、版式规范（要用 Figma / Canva / PPT 自己改时照这个来）

| 项目 | 规范 |
| --- | --- |
| 画布 | 3508 × 4961 px（300dpi）；若印刷厂要 3mm 出血，用 3544 × 5031 px |
| 安全边距 | 左右 168 px、上 150 px、下 132 px（≈ 14mm / 12.7mm / 11mm） |
| 主色 | 品牌渐变 #6366F1 → #4338CA；强调 #8B8CFF、#C4B5FD |
| 底色 | #06080F（近黑，带 4% 白网格） |
| 正文字号 | 标题 268 px / 副标 52 px / 卡片标题 46 px / 说明 33 px / 数据 92 px |
| 字体 | 微软雅黑 Bold / Heavy（或思源黑体 Heavy），西文 Segoe UI |
| 圆角 | 卡片 40 px、手机 82 px、二维码卡 34 px、胶囊 999 px |
| 图片 | 手机上屏截图 1290 × 2796（3 倍图），印刷建议 ≥ 2 倍目标尺寸 |
| 二维码 | 白底留白 ≥ 4 个模块，最小边长 25 mm（此处 30 mm） |

### 印前提醒

- 上面这张 PNG 是 **RGB**。印刷厂通常要 CMYK，交付时让对方转，或者自己转一次（深靛蓝在 CMYK 里会变闷，可把底色压到 #0A0C18、把紫色提亮 3–5% 抵消）。
- 若印在哑光纸上，深色大色块容易看出滚筒纹，建议局部 UV 或覆哑膜。
- PDF 已含完整位图，直接给印刷厂即可；要可编辑文字则从 `docs/poster/src/poster.html` 重新导出。
