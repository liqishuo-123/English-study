# 四六级英语工作台

> 移动优先、零依赖、离线可用的大学英语四六级备考工具。

**在线试用**：<https://liqishuo-123.github.io/English-study/>（GitHub Pages，支持「添加到主屏幕」）

本仓库是一个纯原生 HTML + CSS + JavaScript 的单页应用，不依赖任何 npm 包、构建工具或外部 CDN。电脑上直接双击 `index.html` 即可打开；部署到任意免费静态托管后，手机可「添加到主屏幕」像原生 App 一样离线使用。

## 功能速览

- **今日**：考试倒计时、教练计划进度、每日计划（复习 / 新词 / 阅读 / 写作 / 精听五类任务）、勾选打卡、六个模块入口
- **学习教练**（二级页，新增）：按你的真实数据制定分阶段计划、定期复盘学习进度 / 易错点 / 易错单词；配了 API 由大模型写，没配用本地统计模板；页内可直接和教练对话
- **单词**：4491 个四六级词 + 67 条短语，SM-2 间隔重复、三档反馈、拼写 / 选择自测、发音朗读、筛选与已掌握标记
- **真题训练**（二级页）：选词填空、长篇匹配、仔细阅读三类原创仿真题，支持导入自己整理的真题
- **写作与翻译库**：模板 / 万能句型 / 高级替换 / 翻译句式，支持自建、搜索、复制、AI 批改与译文自测
- **听力精听**：内置示例材料或粘贴任意英文，逐句朗读、语速与重复次数可调、听写对照（逐词高亮漏听 / 多写）
- **AI 学习助教**：对话式智能体，能读写应用里的真实数据——查状态、搜词、加词、改计划、出题、存素材、跳转页面
- **我的**：打卡热力图、掌握率曲线、各模块数据、语音与语速、AI 配置、备份导入导出

## 技术约束

- 无 ES Module：`file://` 下模块会触发 CORS，因此全部使用传统 `<script>` + `window.App.*` 命名空间
- 无外部 CDN：所有图标为内联 SVG 或自生成 PNG；样式全部手写
- 存储：浏览器 `localStorage`，提供一键导出/导入 JSON 备份
- 离线：Service Worker + Web App Manifest，静态资源预缓存；脚本样式走「先缓存后后台更新」
- 语音：浏览器内置 Web Speech API，无需任何音频文件与网络请求
- AI：可选 OpenAI 兼容接口，支持 Function Calling（不支持时自动降级为 JSON 协议）；无 Key 时功能降级，其余功能完全离线可用

## 快速开始

### 0. 一键启动本地服务（推荐）

双击 `启动.cmd`，会自动启动零依赖静态服务器并打开浏览器：

```
http://127.0.0.1:8123/
```

也可以手动运行：

```bash
node serve.js 8123          # 只监听本机
node serve.js 8123 0.0.0.0  # 同一局域网内手机也能访问
```

用 `http://127.0.0.1` 而不是双击文件，是为了让 Service Worker、PWA 安装和麦克风/剪贴板等能力正常生效。

### 1. 本地双击打开

直接双击 `index.html` 也能用。`file://` 下 Service Worker 不会注册，但所有功能均可正常使用。

推荐 Chrome / Edge / Safari。


### 2. 手机「添加到主屏幕」

部署到支持 HTTPS 的静态托管后（见下方部署），在手机上：

- **iOS Safari**：分享 → 「添加到主屏幕」
- **Android Chrome**：菜单 → 「添加到主屏幕」/「安装应用」

首次联网打开后，静态资源会被缓存，之后无网络也能使用。

### 3. 部署到免费静态托管

任选其一即可：

- **EdgeOne Pages / Cloudflare Pages / Vercel**：拖拽整个项目文件夹上传
- **GitHub Pages**：将本仓库推送到 GitHub，开启 Pages（分支选 `main`，路径选 `/`）

> 注意：静态托管必须提供 HTTPS，否则 PWA 安装与 Service Worker 不会生效。`file://` 仅在电脑本地预览。

## 导入与备份

### 导出备份

进入「我的 → 导出备份」，将当前所有学习进度、设置、自建素材、错题本打包为 JSON 文件保存到本地。为安全起见 **导出的文件里 API Key 会被清空**，换设备后重填一次即可。

### 导入备份

进入「我的 → 导入备份」，选择之前导出的 JSON 文件即可恢复。

### 导入词库

支持 CSV，表头见 `docs/templates/words-template.csv`。`freq` 字段可取 `high/mid/low`，`stage` 可取 `hs/beyond`。

### 导入真题

支持 JSON，结构见 `docs/templates/quiz-template.json`。导入时会自动校验字段，失败行会保留在输入框中。

## 配置 AI

进入「我的 → AI 接口配置」，填写：

- Base URL（如 `https://api.deepseek.com/v1`，也可用其他 OpenAI 兼容服务）
- API Key
- 模型名称（如 `deepseek-chat`）

配置页内置 6 个服务商预设（DeepSeek / OpenAI / 通义千问 / 智谱 / Kimi / 本地 Ollama），点一下自动填好地址与模型。

两种用法：

1. **单点功能**：单词详情里的例句生成、长难句解析，写作素材里的作文批改。
2. **AI 学习助教**（`#/agent`，**底部导航最左边的「AI 助教」**，一级入口，常驻品牌色）：完整对话页，模型可以调用 10 个工具直接操作应用数据：

   | 工具 | 作用 |
   | --- | --- |
   | `get_status` | 读当前进度、目标、倒计时、错题数 |
   | `list_words` | 按到期 / 薄弱 / 生词 / 已掌握等范围取词 |
   | `search_word` | 查词、查释义（含中文匹配） |
   | `add_words` | 批量加入生词本 |
   | `set_word_state` | 标记已掌握 / 收藏 |
   | `update_plan` | 修改每日目标与考试日期 |
   | `add_quiz` | 把模型出的题直接入库 |
   | `save_material` | 把范文 / 句型存进写作库 |
   | `search_material` | 检索写作素材 |
   | `navigate` | 对话结束后跳转到对应页面 |

   例：「把每天新词改成 40 个，顺便给我出两篇四级阅读」——助教会真的改设置并把题录进题库。**密钥仅保存在本机浏览器，前端直连会暴露给服务商，仅供个人自用。**

3. **学习教练**（`#/coach`）：一个专门盯「计划与复盘」的智能体，和助教共用工具层，多了 4 个教练工具：

   | 工具 | 作用 |
   | --- | --- |
   | `get_stats` | 取近 N 天逐日数据、正确率、目标达成率、最记不住的词、错题分布 |
   | `get_plan` | 读当前计划与进度 |
   | `save_plan` | 把模型生成的分阶段计划存下来（可同步每日目标） |
   | `save_report` | 把复盘（问题 / 易错词 / 下一步 / 目标调整）存进时间线 |

   - **制定计划**：回答 4 个问题（目标分、每天时长、每周天数、薄弱项），生成「基础期 / 强化期 / 冲刺期」分阶段计划，直接写进每日目标；不能配 AI 时用本地模板（按剩余天数、每分钟 0.55 词估新词量、正确率低于 60% 自动打折）。
   - **定期复盘**：按设置的天数（1 / 3 / 7 天）在首页和教练页亮提醒；复盘会给出 0~100 分、做得好的、要注意的问题（带证据和改法）、易错词（带记法）、明天先做这些，并可一键把建议写回每日目标。
   - **每天第一次打开的提醒**：到复盘时间后，当天首次打开应用会弹一次「该复盘了」，写清距上次多久、这几天的计划走到第几天，一键生成（有 Key 走 AI，没有就出数据版）；点「今天先不」当天不再打扰。**它只提醒、不自动发请求**，绝不偷偷花你的 API 额度。
   - **页内对话**：教练页点右上角 ✨ 或「和教练聊聊」，直接在底部面板里聊，不用跳转；聊的过程中存了计划 / 复盘，关掉面板页面会自动刷新。
   - 所有数据都从 `logs`、`progress`、`wrongbook` 现算，没有任何上传；只在点「生成」或发消息时才把统计摘要发给你的模型接口。

## 自测

仓库自带五个无第三方依赖的测试脚本（需要本机 Chrome / Edge）：

```bash
node serve.js 8123 &
node tools/probe.mjs        # 9 个路由冒烟：渲染、报错、截图
node tools/scenario.mjs     # Agent 工具层的端到端断言
node tools/ui-test.mjs      # 听力/写作/助教/今日页交互回归
node tools/coach-test.mjs   # 学习教练全链路：本地计划/复盘、4 个工具、AI 解析与降级、对话面板
node tools/coach-audit.mjs  # 教练页版式自检：溢出、裁切、可点区域、视觉属性
```

脚本会启动 headless 浏览器、清掉 Service Worker 旧缓存，再跑断言并输出 PASS / FAIL。

## 常见问题

**Q：为什么不用 Vue / React / Tailwind？**  
A：为了保证离线可用、PWA 缓存完整、电脑上双击 `index.html` 也能跑，同时降低维护成本，项目刻意保持零依赖。

**Q：iOS 添加到主屏幕后数据会丢吗？**  
A：数据存在 Safari 的 localStorage 中，只要不清除网站数据就不会丢失。建议定期「导出备份」。

**Q：词库可以扩容吗？**  
A：可以。通过「我的 → 导入词库」追加 CSV；或直接在 `js/data/` 中新增数据文件并在 `index.html` 中按顺序引入。

**Q：如何更新版本？**  
A：改完代码重新部署即可。`sw.js` 里 `CACHE_VERSION` 控制整包缓存版本；脚本与样式另外走「先缓存后后台更新」，所以即使忘了改版本号，第二次打开也会拿到新代码。开发时可用 `Ctrl+Shift+R` 强制刷新。
